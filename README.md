# gwcadet.com

The public website for **GW Cadet**, a Google Sheets add-on for Google Workspace
administrators, made by WolfLoop Technology. Static HTML and CSS, served by
GitHub Pages at https://www.gwcadet.com.

| Path | What it is |
|---|---|
| `index.html` | Homepage (hand-built) |
| `privacy/`, `terms/`, `support/` | Generated by `node build.js` from the policy Markdown |
| `css/site.css` | Styles |
| `fonts/` | Self-hosted Figtree (SIL OFL 1.1) |
| `img/` | The GW Cadet mascot, and screenshots of the add-on on a test domain with sample users (each has a .json note of its origin) |
| `CNAME` | `www.gwcadet.com` for GitHub Pages |

## Updating the policies

The privacy policy and terms are written once, in
`sheets-addon-lite/verification/PRIVACY_POLICY.md` and `TERMS_OF_SERVICE.md`
in the GW Cadet project. After editing either, run `node build.js` here and
commit the regenerated `privacy/` and `terms/` pages.

## Install links

Every Install button points to the Marketplace listing,
https://workspace.google.com/marketplace/app/gw_cadet/72688054574, and opens it
in a new tab: three in `index.html` and the nav in `build.js`.
